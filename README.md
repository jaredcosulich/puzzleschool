# The Puzzle School

The website for [The Puzzle School](https://puzzleschool.org) — an educational
philosophy focused on developing the metacognitive skills for navigating ambiguity.

This is a [Next.js](https://nextjs.org) app exported as a fully static site and
deployed to GitHub Pages (custom domain `puzzleschool.org`) via the GitHub Actions
workflow in `.github/workflows/nextjs.yml` on every push to `main`.

## Getting Started

```bash
npm install
npm run dev      # http://localhost:3000
```

## Build

```bash
npm run build    # static export to ./out
```

`./out` is generated by CI and is not committed.

## Structure

- `src/app/` — pages (App Router). Content pages: home, `learn_more`, `advisors`,
  `day_in_the_life`, `programs` (+ program detail pages), `technologies`, `contact`.
- `src/app/codepuzzle/` — the interactive Code Puzzle (a turtle-graphics interpreter).
  Puzzle content lives in `src/lib/puzzles.ts`; the engine is `src/components/CodePuzzle.tsx`.
- `src/components/` — shared layout (`Header`, `Logo`, `Footer`) and helpers.
- `src/app/globals.css` — a small Bootstrap-4-alpha-compatible grid/utility shim
  (the content pages were ported from the original Bootstrap-based Rails app).
- `public/` — images, PDFs, printable Code Puzzle cards, and the `CNAME`.

## History

This site was previously a Ruby on Rails app (hosted on Heroku). The content and the
interactive Code Puzzle were ported to this static Next.js site. The original Rails
app, its earlier Node.js incarnation, and the standalone puzzle games (XYFlyer,
Language Scramble, Circuitous, etc.) remain available in this repo's git history and
in the older remote branches (`rails`, `node`, `master`, `redesign`, ...).

The dynamic features of the old site that cannot run on static hosting — Stripe
payments, email signup, the contact form, and the puzzle-management CRUD — were
intentionally dropped. The Code Puzzle's original database-backed puzzles were lost
with the Heroku database, so the puzzles here are reconstructed samples running on
the same engine.
