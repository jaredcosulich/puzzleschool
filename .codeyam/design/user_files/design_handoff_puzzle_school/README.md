# Handoff: The Puzzle School — marketing site (Home + About)

## Overview
Two pages for The Puzzle School, an experimental K–12 school whose subject is
ambiguity: how to notice it, stay with it, and move through it. The site's job is
to explain the idea, carry the identity, and collect contact from interested
families while the school is still in an exploratory phase.

The visual system has one distinguishing device: **line structures generated by
mathematical rules** (a Fibonacci square spiral, a sine-wave field, a dragon
curve, a branching tree, a morse-code rule). Each is drawn at hairline weight,
anchored to a page edge or a section seam, and deliberately **left incomplete** —
a limb ends bare, a curve stops before it closes. They are not decoration for its
own sake; they carry the "one piece is always missing" idea. Preserve that
incompleteness when reimplementing.

## About the design files
`index.html` and `about.html` in this bundle are **design references created in
HTML** — prototypes showing intended look and structure, not production code to
ship. The task is to recreate them in the target codebase's existing environment
(React, Vue, Astro, plain templates, whatever is already there) using its
established patterns. If no codebase exists yet, pick the framework that suits a
small marketing site and implement the designs there.

Both files are self-contained: open either directly in a browser. Each carries an
inline `<svg>` sprite of logo symbols at the top of `<body>`; the page markup
follows in `div.page`. All styling is inline on the elements — that is an
artifact of the prototype, not a recommendation. Extract it into whatever the
codebase uses (CSS modules, Tailwind, styled-components).

## Fidelity
**High-fidelity.** Colors, typography, spacing, and copy are final as shown, at a
fixed 1280px design width. Recreate the UI closely. Two known gaps, both listed
under Open items below: the pages have no responsive behavior, and the structures
are hand-placed with absolute offsets.

## Interactions & Behavior
Static marketing pages. What exists:

- **Links:** default `color: inherit; text-decoration: none`. Hover: `opacity: .7`.
  Apply to every anchor including the buttons.
- **Navigation:** "About" → About page. "Contact" and the Contact button →
  contact destination (a form or `mailto:`, not yet designed — confirm with the
  owner). "Learn More" → currently unrouted; confirm the target.
- **No animation, no transitions, no loading or error states, no forms** in the
  current design. If you add a hover transition, keep it short (120–160ms) and
  limit it to opacity.
- **Structures** are decorative: `pointer-events: none`, and they should be
  `aria-hidden="true"` in the implementation.

## State Management
None. Both pages are static. If Contact becomes a real form, it will need its own
state and validation — not specified here.

## Assets
- **Logo mark**: inline SVG, defined as `<symbol>` elements in the sprite at the
  top of each file. Eight-point compass rose built from interlocking puzzle-piece
  shapes. Variants: `#signal` (on paper), `#signalNight` (on ink),
  `#signalOnGold`, `#signalOnTeal`, `#signalInk`, `#signalGap` (one piece drawn
  as a dashed outline). Inner separation lines are `#16211e` in every variant —
  the mark never uses white inner lines. Export these to a shared icon component
  or SVG file rather than duplicating the sprite per page.
- **Structures**: inline SVG paths, generated from rules (Fibonacci, sine, Koch,
  dragon curve, binary tree, morse). Generating them in code is preferable to
  pasting the path data, so the incompleteness stays parameterised.
- No raster images, no icon font, no third-party assets.

## Open items for the owner
- Contact destination: form, `mailto:`, or a third page?
- "Learn More" target.
- Responsive behavior below 1280px is undesigned. Suggested first pass: keep the
  page fluid with the same gutters, collapse the card grid to one column below
  ~840px, drop the structures rather than scaling them, and reduce display sizes
  by roughly 40% on small screens.
- Accessibility: verify contrast on `#8b8378` footer text over `#faf7f1` (about
  3.3:1 — passes for the 11px bold size only marginally; consider darkening).
